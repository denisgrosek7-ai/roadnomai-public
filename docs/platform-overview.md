# RoadNomai Platform Overview

RoadNomai is designed as a shared travel platform core that can support multiple product directions without splitting the system into separate stacks.

## Platform Intent

The platform is built to support:

- white-label deployments for partner-branded experiences
- partner-aware B2B surfaces
- direct branded B2C experiences
- a shared engineering base across client and backend layers

## Core Idea

RoadNomai aims to keep one modular core while allowing controlled variation in:

- branding and visual identity
- routing posture
- feature exposure
- deployment context
- partner-facing configuration

## Public-Safe Scope

This public repository communicates:

- the platform direction
- architectural concepts
- public-safe schemas and contracts
- engineering discipline around verification and observability

It does not expose:

- private tenant or partner configuration
- sensitive operational procedures
- internal rollout logic
- restricted support or control-plane details

## Public Positioning

The public positioning is straightforward:

- one shared platform
- multiple product directions
- controlled configurability
- verification-oriented engineering
