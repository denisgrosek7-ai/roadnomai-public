# B2C Overview

RoadNomai is also designed to support direct branded consumer-facing product experiences from the same shared platform foundation.

## B2C Goal

The B2C posture keeps the branded user-facing experience on the same core platform rather than splitting consumer flows into a separate product stack.

## Public-Safe Interpretation

In the public repository, B2C should be understood as:

- a supported product direction
- a branded consumer-facing use of the shared core
- an architectural option enabled by modular platform design

## Why It Matters

This allows the platform to communicate a clear model:

- one shared foundation
- multiple product directions
- bounded customization instead of parallel codebases
