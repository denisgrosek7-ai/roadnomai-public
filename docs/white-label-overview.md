# White-Label Overview

RoadNomai is intended to support partner-branded experiences from a shared platform core.

## White-Label Goal

The white-label model is based on keeping the core product consistent while allowing controlled variation in:

- brand identity
- visual presentation
- product posture
- route exposure
- selected feature availability

## Platform Fit

This model is useful when one platform needs to serve multiple deployment contexts without maintaining separate product stacks.

## Public-Safe Interpretation

In the public repository, white-label should be understood as:

- architecture-capable
- configuration-oriented
- partner-aware by design

It should not be interpreted as a publication of partner-specific deployments, configurations, or internal provisioning processes.

## What Remains Private

- partner onboarding details
- branding asset pipelines
- private routing rules
- restricted integration specifics
- operational rollout logic
