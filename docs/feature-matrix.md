# Feature Matrix

This matrix describes the public-safe platform view, not a live commercial entitlement sheet.

| Area | Shared Platform Core | White-Label Direction | B2B Direction | B2C Direction |
| --- | --- | --- | --- | --- |
| Shared planning foundation | Yes | Yes | Yes | Yes |
| Configurable branding posture | Yes | Primary use | Supported | Supported |
| Partner-aware deployment model | Yes | Supported | Primary use | Limited / contextual |
| Branded consumer-facing posture | Yes | Supported | Possible | Primary use |
| Public-safe schemas and contracts | Yes | Yes | Yes | Yes |
| Observability and verification discipline | Yes | Yes | Yes | Yes |
| Private operational provisioning | Private | Private | Private | Private |
| Sensitive commercial logic | Private | Private | Private | Private |

## Reading the Matrix

- `Yes` means the platform is designed with that capability in mind.
- `Primary use` means the product direction is a natural fit for that model.
- `Private` means the implementation or operational details are intentionally not exposed in this public repository.

This matrix is architectural and product-positioning oriented. It is not a statement that every private operational capability is publicly implemented here.
