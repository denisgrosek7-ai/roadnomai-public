# Public Status

This repository should be read as a public-safe platform repository, not as a publication of private production internals.

## Publicly Communicated Today

- RoadNomai is positioned as a shared platform core
- the architecture is intended to support white-label, B2B, and B2C directions
- the engineering posture emphasizes modularity, configurability, observability, and verification discipline

## Publicly Available Here

- platform-facing documentation
- architecture overviews
- selected public-safe engineering documentation
- release-oriented public notes

## Intentionally Not Public Here

- partner-specific runtime configuration
- private operational governance
- sensitive commercial or billing internals
- private support workflows
- incident playbooks
- internal debug evidence

## Status Framing

The public repository communicates:

- platform direction
- public-safe technical concepts
- engineering discipline

It does not claim to be a full publication of private operational readiness or private production control surfaces.
