# B2B Overview

RoadNomai is designed to support partner-aware B2B deployment contexts from a shared core.

## B2B Goal

The platform is intended to support agency, integration-oriented, and partner-facing product models where one core can serve multiple controlled contexts.

## Public-Safe B2B View

Publicly, the B2B posture should be understood as:

- partner-aware architecture
- controlled configuration across deployment contexts
- shared platform logic with bounded surface differences

## What the Public Repo Shows

- public-safe architectural intent
- documentation of modularity and configuration posture
- engineering emphasis on contracts, verification, and observability

## What the Public Repo Does Not Show

- live partner identities
- private onboarding or provisioning workflows
- sensitive commercial logic
- internal control-plane procedures
